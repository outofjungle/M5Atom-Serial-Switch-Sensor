# Vendored library: TinyCBOR

This directory holds a partial copy of TinyCBOR. It encodes and decodes
Concise Binary Object Representation (CBOR) data. See `docs/04-cbor-encoding.md`.

| Field | Value |
|---|---|
| Upstream project | https://github.com/intel/tinycbor |
| Version | v0.6.0 |
| Commit | d393c16f3eb30d0c47e6f9d92db62272f0ec4dc7 |
| License | MIT. See `LICENSE` in this directory. |

Only the encoder and parser source files are copied here. The pretty-printer, JSON conversion,
and build-system files from the upstream project are not needed by this firmware and are not
included.
